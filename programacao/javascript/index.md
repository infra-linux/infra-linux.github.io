# JavaScript

JavaScript é a linguagem da web. Roda no navegador, para deixar páginas interativas, e também no servidor, com o Node.js. É uma boa primeira linguagem para quem quer entrar em desenvolvimento.

## Por onde começar

1. Leia o **Guia de Estudo** na ordem, testando cada exemplo no Console do navegador (`F12`).
2. Faça os exercícios do final do guia.
3. Monte um pequeno projeto, como uma lista de tarefas, para fixar o conteúdo.
